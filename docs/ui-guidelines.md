# Diretrizes visuais

O tema padrão é dark: `#080808` como fundo, `#151517` em cards e `#29292D` em bordas. Verde é semântico para ganho/sucesso, rosa para porquinhos e metas, dourado para atenção/conquistas e vermelho somente para despesa/erro/atraso.

Use Manrope ou Inter, bordas de 12–16px e animações sutis abaixo de 220ms. A sidebar é fixa no desktop e a navegação inferior assume no mobile. Valores devem respeitar a preferência de privacidade visual armazenada localmente.
